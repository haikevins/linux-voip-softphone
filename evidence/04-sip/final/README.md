# Phase 4 final evidence

This directory is generated by:

```bash
sudo ./scripts/verify_phase4.sh --capture
```

The generated text files record the final idle Asterisk state, current SIP contacts, the recent Git
history, and a concise Phase 4 verification summary. The established-call evidence itself remains in
`evidence/04-sip/call-flow/`, while the sanitized signaling summary remains in
`evidence/04-sip/protocol/`.

Do not add raw SIP logger captures to this directory.
